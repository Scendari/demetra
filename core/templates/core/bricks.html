Briques de représentation

Une représentation est un document JSON qui assemble ces briques. Demetra valide le document, puis dessine lui-même : aucun code fourni par une IA ou un utilisateur n'est exécuté. Si une brique manque, l'IA la signale et compose en attendant avec celles-ci.
