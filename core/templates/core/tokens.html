Jetons d'accès

Un jeton permet à une IA externe (Copilot, Claude Code, Codex, Cursor…) d'agir sur vos études par l'API, en votre nom et dans la limite de vos droits. Il ne peut ni rendre un avis, ni partager sans votre confirmation.

Brancher une IA : le plus simple

Dites à votre IA (mode Agent de Copilot, Claude Code, Codex, Cursor…) :

Connecte-toi à mes études Demetra en suivant {{ origin }}/llms.txt

Elle vous donnera un lien : ouvrez-le, vérifiez le code, cliquez « Autoriser ». Elle range son accès elle-même : aucun jeton à copier. Saisir un code

{% endif %} {% if fresh %}

Jeton « {{ fresh.name }} » créé — copiez-le maintenant

Il ne sera plus jamais affiché : Demetra n'en garde qu'un condensé.

{{ fresh.secret }}

1. Rangez-le dans votre session, pas dans la conversation

Ne collez jamais le jeton dans le chat de votre IA. Lancez une fois cette commande dans un terminal, puis quittez et relancez votre éditeur (VS Code, Cursor…).

macOS (zsh)

echo 'export DEMETRA_TOKEN="{{ fresh.secret }}"' >> ~/.zshrc

Linux (bash)

echo 'export DEMETRA_TOKEN="{{ fresh.secret }}"' >> ~/.bashrc

Windows

setx DEMETRA_TOKEN "{{ fresh.secret }}"

2. Donnez ce message à votre IA

Il ne contient pas le jeton. Votre IA doit pouvoir lancer des commandes : mode Agent de Copilot, Claude Code, Codex, Cursor.

Tu peux travailler sur mes études Demetra ({{ origin }}).
Lis d'abord les règles pour les IA : {{ origin }}/api/v1/guide/agents?format=md
Mon jeton est dans la variable d'environnement DEMETRA_TOKEN : ne me le demande pas, ne l'affiche jamais, ne le mets jamais dans une URL, écris toujours $DEMETRA_TOKEN dans tes commandes.
Appelle l'API depuis le terminal avec curl -H "Authorization: Bearer $DEMETRA_TOKEN" (PowerShell : curl.exe et $env:DEMETRA_TOKEN) ; ton outil de lecture de page web ne peut pas s'authentifier.
Commence par GET {{ origin }}/api/v1/me puis lis {{ origin }}/api/v1/guide?format=md.

Pour ne pas le répéter à chaque conversation, mettez les consignes permanentes dans le fichier d'instructions de votre projet (.github/copilot-instructions.md, AGENTS.md ou CLAUDE.md) : modèle dans Brancher une IA en sécurité.
